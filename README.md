# SecureTask Distributed

SecureTask ist ein AI-unterstützt entwickelter verteilter ToDo-Manager.

Das Projekt besteht aus drei getrennten Modulen:

- frontend: React-Oberfläche
- backend: REST-API mit Node.js/Express
- worker: separater Prozess zur Verarbeitung von Deadlines und Statusänderungen

Ziel ist es, den Einsatz von Vibe Coding, AI-gestützter Entwicklung und verteilter Software praktisch zu dokumentieren.
